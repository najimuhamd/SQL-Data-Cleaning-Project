# SQL Data Cleaning Project

This project focuses on cleaning and preparing a layoffs dataset using SQL.

The original dataset was `layoffs.csv`. It was imported into MySQL, where SQL queries were used to identify and fix different data-quality issues.

## Project Workflow

1. Import the raw `layoffs.csv` dataset into MySQL.
2. Explore the dataset and identify data-quality issues.
3. Remove duplicate records.
4. Handle missing and NULL values.
5. Standardize inconsistent data.
6. Correct and clean the data.
7. Remove unnecessary data.
8. Review the cleaned dataset and prepare it for further analysis.

## Data Cleaning

The cleaning process includes:

- Removing duplicate records
- Handling missing and NULL values
- Standardizing data
- Correcting inconsistent values
- Removing unnecessary data

## Tools Used

- MySQL
- SQL
- Microsoft Excel

## Files

- `layoffs.csv` — Original dataset
- `DATA_CLEAN.sql` — SQL queries used for data cleaning

The main purpose of this project was to gain practical experience with SQL and understand how raw data can be cleaned and prepared for further analysis.
